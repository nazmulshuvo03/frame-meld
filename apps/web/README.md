# FrameMeld web

This is the FrameMeld web app: a Next.js frontend for signup/login, the
Meld dashboard, and the story editor.

See the [repo root README](../../README.md) for what FrameMeld is, how to
run the whole stack locally, and current project status.

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. Requires the backend API running — see the
root README's "Running locally" section.
