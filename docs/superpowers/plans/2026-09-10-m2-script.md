# M2 (Script) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A user turns their story into an editable shot list, and editing the story
marks that shot list out of date without destroying it.

**Architecture:** M2 adds the first background work in the system. An LLM call is too
slow for a request, so it becomes a `jobs` row plus an arq task on Redis. One LLM call
produces the whole script — scenes and their shots together — through a provider adapter
whose default implementation is a deterministic stub, so every test runs without a
network. The staleness engine goes live: each row records a `content_hash` of what it
says and an `input_hash` of what produced it, and `recompute_staleness` compares the
stored `input_hash` against a freshly computed one whenever the story changes.

**Tech Stack:** Python 3.12 / FastAPI / SQLAlchemy 2.0 async / Alembic / arq + Redis /
httpx · Next.js 16.3.4 / React 19.2.8 / Tailwind v4 / Vitest · Postgres 16 · conda

**Spec:** [`docs/superpowers/specs/2026-09-09-framemeld-design.md`](../specs/2026-09-09-framemeld-design.md)

**Predecessor:** [`docs/superpowers/plans/2026-09-09-m1-foundation.md`](2026-09-09-m1-foundation.md).
Its 87 execution rulings are in [`docs/superpowers/m1-decisions.md`](../m1-decisions.md).
Read that file before Task 1 — several constraints below are compressed from it.

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim
from the spec or from M1's shipped code.

**Toolchain**

- Python **3.12** via **conda**, env name `framemeld`. Never `uv`, never `venv`.
  Every backend command is prefixed `conda run --no-capture-output -n framemeld …`.
- Node **20+** (developed against v25.9.0). npm, not pnpm or yarn.
- Repo root is `F:\FrameMeld`. Backend package root is `services/backend`;
  `pyproject.toml`, `alembic.ini` and `migrations/` all live there. `environment.yml`
  lives at the **repo root**, not in `services/backend`.
- Postgres 16 and Redis 7 both come from `docker-compose.yml` at the repo root.

**Database and models**

- Every enum column is built with the four-argument helper (Task 2 moves it to
  `framemeld/models/columns.py`). All four arguments are load-bearing:
  `native_enum=False`, `create_constraint=True`, `name=…`, `values_callable=…`.
  Omitting `create_constraint=True` silently produces an unconstrained VARCHAR;
  omitting `values_callable` silently stores `'STORY'` instead of `'story'`.
- Python enums are `enum.StrEnum`.
- **Every timestamp comes from `datetime.now(UTC)` in application code**, assigned
  explicitly. Never rely on `server_default=func.now()` or `onupdate=func.now()` for a
  value a test or an ordering depends on: Postgres's `now()` is frozen for the whole
  transaction, so two rows written in one transaction share a timestamp. The server
  defaults stay on the columns as a fallback for other insert paths.
- Migrations are generated with `alembic revision --autogenerate`, then **read and
  corrected by hand**. Autogenerate does not emit CHECK constraints written as
  `CheckConstraint(...)` in `__table_args__` reliably — verify each one is present.
- UUID primary keys: `mapped_column(PgUUID(as_uuid=True), primary_key=True, default=uuid.uuid4)`.

**Hashing**

- `canonical_hash` (`framemeld/hashing.py`) accepts **only JSON-native values** and
  raises `TypeError` otherwise. This is deliberate — do not "fix" it with `default=str`.
  `duration_sec` is a `Decimal`, so every call site must convert it explicitly with
  `str(value)`. `uuid.UUID` must become `str(value)`. `datetime` must not be hashed at all.
- **Downstream depends on upstream's `content_hash`, never its `input_hash`**
  (spec §4.1). `content_hash` = what a row says now. `input_hash` = what produced it.

**Authorization**

- Every read of a user-owned row goes through **one funnel**: `melds.service.get_meld`,
  which is the only place a `Meld` is selected by id, and it always filters on
  `user_id` and `deleted_at IS NULL`. Scene, Shot and Job lookups in this milestone
  resolve their Meld through it first, then filter the child row by `meld_id`.
- A row belonging to another user returns **404, not 403** — a 403 confirms the row
  exists.
- `HTTPException` instances are created fresh per raise by a `_not_found()`-style
  factory. A module-level instance accumulates tracebacks, each frame retaining that
  request's session and user.

**Tests**

- `pytest` with `asyncio_mode = "auto"`. No `@pytest.mark.asyncio` decorators.
- Call `db.expire_all()` before asserting that something was *persisted*. It is a
  **synchronous** method even on `AsyncSession`; `await`ing it raises `TypeError`.
  Without it the identity map returns the in-memory object and the assertion cannot
  fail. Two M1 tests shipped broken for exactly this reason.
- Tests never reach the network. The default LLM provider in tests is the stub.
- Backend gates, all three must be clean:
  `pytest`, `ruff check src tests`, `ruff format --check src tests`.
- Frontend gates, all four must be clean:
  `npm run lint`, `npx tsc --noEmit`, `npm run build`, `npm test`.

**Style**

- `ruff` line length 100; selected rules `E4, E7, E9, E501, F, I, UP, B, DTZ, RUF`.
- Comments explain **why**, not what. M1's codebase sets the density — match it.
- No `# type: ignore`, no `Any` where a real type exists.

**Product values fixed by the spec**

- `shots.duration_sec` ≤ **5.0** seconds — a database CHECK constraint, and enforced in
  the generator's JSON schema (spec §8).
- Target film: 1–3 minutes, **10–30 shots** (spec §1).
- `camera` ∈ `wide, medium, close, insert, establishing`.
- `dialogue_kind` ∈ `none, narration, off_screen, on_screen`.
- `jobs.idempotency_key` is **unique** and equals `hash(kind, target_id, input_hash)`
  (spec §5.4).
- Job kinds used in M2: `generate_script`. The enum carries the full spec list.
- LLM provider default: OpenRouter free tier. Free models are rate-limited to roughly
  20 req/min and 200 req/day and the roster changes without notice (spec §6.2) — which
  is why the adapter boundary is a requirement, not a nicety.
- **No credits in M2.** The `credit_ledger`, pricing and quote/hold/settle arrive in M3.
  Do not add a credits column or a balance check anywhere.

## Decisions taken up front

These are settled. Do not relitigate them mid-task; if one turns out to be wrong,
escalate rather than quietly choosing differently.

**D1 — `stories.input_hash` is renamed to `stories.content_hash`.** It was always a
content hash: a story has no generation behind it, the user simply wrote it. The spec
was corrected while planning M2 (see its §4.1 blockquote). This is a breaking change to
`GET /melds/{id}` and `PUT /melds/{id}/story`; the Next.js app is the only consumer and
is updated in the same task.

**D2 — `script_input_hash` is computed from the *current* provider configuration.**

```
script_input_hash = canonical_hash({
    "kind": "script",
    "story_content_hash": <the story's content_hash>,
    "provider": <settings.llm_provider>,
    "model": <settings.llm_model>,
    "params": <SCRIPT_PARAMS, including prompt_version>,
})
```

The same function produces both the staleness comparison and the job's idempotency key,
so a row shown as stale can never turn out to be a silent cache hit when the user presses
Regenerate. The cost of this choice: changing the configured model, or bumping
`prompt_version`, marks every existing script stale. That is operator-initiated, not
user-initiated, and it is *true* — regenerating would produce something different. It is
accepted deliberately.

**D3 — in M2 every scene and every shot in a Meld shares one `input_hash`,** because one
LLM call produces the whole script. A shot's input is the story, not its scene. Editing a
scene heading therefore does **not** make its shots stale.

**D4 — a user edit never changes `state`.** Editing a shot changes its `content_hash`
and nothing else. The row holds what the user wants, so it is not "out of date" —
and M4's shot images will notice the changed `content_hash`, which is the entire point
of the two-hash split.

**D5 — `recompute_staleness` only ever moves rows between `fresh` and `stale`.** Rows in
`empty`, `generating` or `failed` are left alone. The `stale → fresh` direction matters:
spec §4.4 promises that reverting an edit restores the cache hit and costs nothing.

**D6 — the frontend test harness is Vitest, not `node --test`.** M1's close-out sketched
`node --test` with a fake clock. Node's type stripping does not handle JSX, so a
`node --test` harness would mean writing React tests in `React.createElement` calls with
no types. Vitest gives TSX, jsdom and fake timers for one devDependency group. The
requirement — a real regression guard on `useAutosave` — is unchanged.

**D7 — the login rate limiter fails open when Redis is unreachable,** logging a warning.
Failing closed would make a Redis outage a total login outage, and Redis being down
already means the job queue is down. Documented in the README's Known gaps.

**Amended during the pre-flight scan** (see `.superpowers/sdd/2026-09-10-m2-script/progress.md`):

- **R1** — `MAX_SHOTS` lives in `models/script.py` beside `MAX_SHOT_SECONDS`, and both
  `script/hashes.py` and `script/generation.py` import it. `SCRIPT_PARAMS` must never
  restate a limit that is defined elsewhere: a drifted copy would leave the input hash
  describing parameters that were not used, and staleness would go quietly wrong.
- **R2** — `ScriptOut` carries no `story_content_hash`. Nothing in M2 reads it.
- **R3** — `SceneOut` (the scene's own fields, and the PATCH response) is separate from
  `SceneDetail(SceneOut)` (adds `shots`, used by the script listing). `update_scene` does
  not eager-load the relationship, so a single schema declaring `shots` would lazy-load
  under asyncio and raise `MissingGreenlet`.
- **R4** — Task 2 also corrects `story_hash`'s docstring.

**Deferred out of M2, on purpose** — record these in the README rather than building them:
adding, deleting or reordering scenes and shots (M2 edits fields, not structure);
moderation of the story text (spec §4.5, lands with M3's credit gate, since its job is to
refuse *before* a hold is taken); job cancellation; multi-worker locking beyond the
idempotency key.

```python
import pytest
from redis.exceptions import RedisError

from framemeld.ratelimit import clear, record_failure, retry_after


class BrokenRedis:
    """Every command raises, which is what an unreachable Redis looks like
    to redis-py once the connection attempt fails."""

    async def get(self, *args, **kwargs):
        raise RedisError("connection refused")

    async def ttl(self, *args, **kwargs):
        raise RedisError("connection refused")

    async def delete(self, *args, **kwargs):
        raise RedisError("connection refused")

    def pipeline(self, *args, **kwargs):
        raise RedisError("connection refused")


async def test_under_the_limit_is_allowed(fake_redis):
    await record_failure(fake_redis, "k", 900)
    assert await retry_after(fake_redis, "k", limit=3) is None


async def test_at_the_limit_reports_a_wait(fake_redis):
    for _ in range(3):
        await record_failure(fake_redis, "k", 900)
    wait = await retry_after(fake_redis, "k", limit=3)
    assert wait is not None
    assert 0 < wait <= 900


async def test_the_window_does_not_slide(fake_redis):
    """The TTL is set once, by the first failure. A later failure must not
    extend it, or a persistent attacker could hold a victim locked out
    indefinitely."""
    await record_failure(fake_redis, "k", 900)
    first_ttl = await fake_redis.ttl("k")
    await record_failure(fake_redis, "k", 900)
    assert await fake_redis.ttl("k") <= first_ttl


async def test_clear_resets_the_counter(fake_redis):
    for _ in range(5):
        await record_failure(fake_redis, "k", 900)
    await clear(fake_redis, "k")
    assert await retry_after(fake_redis, "k", limit=1) is None


@pytest.mark.parametrize("call", ["retry_after", "record_failure", "clear"])
async def test_an_unreachable_redis_fails_open(call):
    """D7: a Redis outage must not become a login outage."""
    broken = BrokenRedis()
    if call == "retry_after":
        assert await retry_after(broken, "k", limit=1) is None
    elif call == "record_failure":
        await record_failure(broken, "k", 900)
    else:
        await clear(broken, "k")
```

Create `services/backend/src/framemeld/redis_client.py`:

```python
from redis.asyncio import Redis

from framemeld.config import settings

_client: Redis | None = None


def get_redis() -> Redis:
    """A process-wide client, created on first use.

    Used as a FastAPI dependency so tests can override it with a fake
    without the real one ever opening a socket. redis-py's asyncio client
    is connection-pooled and safe to share across requests; creating one
    per request would exhaust file descriptors under load.

    decode_responses=True because every value this app keeps in Redis is a
    counter or a short string, and callers should not each have to
    remember to decode bytes.
    """
    global _client
    if _client is None:
        _client = Redis.from_url(settings.redis_url, decode_responses=True)
    return _client


async def close_redis() -> None:
    global _client
    if _client is not None:
        await _client.aclose()
        _client = None
```

- [ ] **Step 6: Write the rate limiter**

Create `services/backend/src/framemeld/ratelimit.py`:

```python
import logging

from redis.asyncio import Redis
from redis.exceptions import RedisError

logger = logging.getLogger(__name__)

_UNAVAILABLE = "rate limiter unavailable (%s); allowing the request"


async def retry_after(redis: Redis, key: str, limit: int) -> int | None:
    """Seconds the caller must wait, or None if it is under the limit.

    Fails open (D7): if Redis cannot answer, the request is allowed and a
    warning is logged. A Redis outage already means the job queue is down,
    so turning it into a total login outage trades a small security window
    for a large availability loss.
    """
    try:
        current = await redis.get(key)
        if current is None or int(current) < limit:
            return None
        ttl = await redis.ttl(key)
    except RedisError as exc:
        logger.warning(_UNAVAILABLE, exc)
        return None

    # ttl is -1 for a key with no expiry and -2 for a missing key; neither
    # should be reachable here, but reporting a negative Retry-After would
    # be worse than reporting a conservative one.
    return max(ttl, 1)


async def record_failure(redis: Redis, key: str, window_seconds: int) -> None:
    """Count one failure into the current window.

    `nx=True` on EXPIRE sets the TTL only when the key has none, which is
    what makes this a *fixed* window: the clock starts at the first failure
    and later failures cannot push it out. A sliding window here would let
    an attacker keep a victim's account locked indefinitely by failing once
    every few minutes.
    """
    try:
        pipe = redis.pipeline()
        pipe.incr(key)
        pipe.expire(key, window_seconds, nx=True)
        await pipe.execute()
    except RedisError as exc:
        logger.warning(_UNAVAILABLE, exc)


async def clear(redis: Redis, key: str) -> None:
    try:
        await redis.delete(key)
    except RedisError as exc:
        logger.warning(_UNAVAILABLE, exc)
```

```python
@router.post("/login", response_model=UserOut)
async def login(
    credentials: Credentials, request: Request, response: Response, db: Db, cache: Cache
) -> User:
    ip_key, email_key = _login_keys(request, credentials.email)
    budgets = (
        (ip_key, settings.login_max_attempts_per_ip),
        (email_key, settings.login_max_attempts_per_email),
    )
    for key, limit in budgets:
        wait = await retry_after(cache, key, limit)
        if wait is not None:
            # Checked before the password is verified, so a limited caller
            # cannot use the status code to tell a right password from a
            # wrong one.
            raise HTTPException(
                status_code=status.HTTP_429_TOO_MANY_REQUESTS,
                detail="Too many login attempts. Try again later.",
                headers={"Retry-After": str(wait)},
            )

    result = await db.execute(
        select(User).where(User.email == credentials.email, User.deleted_at.is_(None))
    )
    user = result.scalar_one_or_none()

    # One error for both "no such user" and "wrong password", so the
    # response body cannot be used to enumerate registered emails.
    # Note the response *time* still can: argon2 only runs when a user
    # matched, so a wrong-password login is measurably slower than an
    # unknown-email one. Signup's 409 already reveals the same fact, so
    # this is accepted for now — but if signup ever stops enumerating,
    # this needs a dummy-hash verify on the user-is-None path.
    if user is None or not verify_password(credentials.password, user.password_hash):
        for key, _ in budgets:
            await record_failure(cache, key, settings.login_window_seconds)
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid email or password"
        )

    # Only the email budget. See _login_keys and the config comment.
    await clear(cache, email_key)

    raw_token = await issue_session(db, user.id)
    await db.commit()
    _set_session_cookie(response, raw_token)
    return user
```

```python
import enum

from sqlalchemy import Enum


def enum_column(enum_cls: type[enum.StrEnum], constraint_name: str, length: int = 20) -> Enum:
    """A VARCHAR column with a named CHECK constraint over the enum's *values*.

    All four keyword arguments are load-bearing and each fails silently if
    omitted:

    - `native_enum=False` avoids a Postgres native enum, which would need an
      `ALTER TYPE` migration every time a member is added.
    - `create_constraint=True` is required. SQLAlchemy 2.0 defaults it to
      False, so `native_enum=False` on its own produces a bare, completely
      unconstrained VARCHAR — no validation at any layer.
    - `name` names the CHECK so a later migration can drop and recreate it.
    - `values_callable` stores `'story'` rather than the member name
      `'STORY'`, keeping the database consistent with the API and with the
      values listed in the spec.

    `length` must be at least as long as the longest *value*, not the longest
    member name. Constraint names are schema-global, so prefix them with the
    table: `shot_camera`, not `camera`.
    """
    return Enum(
        enum_cls,
        native_enum=False,
        length=length,
        create_constraint=True,
        name=constraint_name,
        values_callable=lambda e: [member.value for member in e],
    )
```

```python
    speech_text: Mapped[str] = mapped_column(Text, default="")

    # table that does not exist will not migrate. M3's migration adds the

    input_hash: Mapped[str] = mapped_column(String(64))
    state: Mapped[ArtifactState] = mapped_column(
        enum_column(ArtifactState, "shot_state"), default=ArtifactState.FRESH
    )

    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now()
    )

    scene: Mapped["Scene"] = relationship(back_populates="shots")
```

Note there is deliberately **no** `onupdate=func.now()` on either `updated_at`. Every
write path in this codebase assigns timestamps from `datetime.now(UTC)`; `func.now()` is
frozen for the whole transaction, so reintroducing it here would put an `updated_at`
*before* a `created_at` taken later in the same transaction. That defect was found and
fixed twice during M1 — do not add it back.

```python
import uuid
from decimal import Decimal

from framemeld.config import settings
from framemeld.hashing import canonical_hash
from framemeld.models.script import MAX_SHOT_SECONDS, MAX_SHOTS, Scene, Shot

# Bump whenever the prompt template or the JSON schema changes in a way that
# would produce a different script from the same story. It is part of
# SCRIPT_PARAMS, so bumping it correctly marks every existing script stale.
PROMPT_VERSION = 1

# Imported rather than restated: a drifted copy would leave the hash
# describing parameters that were not used (R1).
SCRIPT_PARAMS: dict[str, object] = {
    "prompt_version": PROMPT_VERSION,
    "temperature": 0.7,
    "max_shots": MAX_SHOTS,
    "max_shot_seconds": f"{MAX_SHOT_SECONDS:.1f}",
}


def _duration_at_column_scale(value: Decimal) -> str:
    """The duration as the database will hold it.

    Decimal("4.5") and Decimal("4.50") compare equal but str() differently,
    and the column is Numeric(4, 2) — so Postgres always hands back the
    two-place form. Hashing str(value) directly would make a shot's hash
    change across a flush-and-reload with nothing edited, and every shot
    would look modified the moment it was read back.
    """
    return f"{value:.2f}"


def _optional_uuid(value: uuid.UUID | None) -> str | None:
    """canonical_hash refuses UUID deliberately, so the conversion is here
    and explicit rather than hidden in a default= hook."""
    return None if value is None else str(value)


def content_hash_for_story(text: str) -> str:
    """What the story *says*. A story has no generation behind it, so this
    is its only hash — see the spec's §4.1 correction."""
    return canonical_hash({"kind": "story", "text": text})


def content_hash_for_scene(scene: Scene) -> str:
    """Every user-editable field of the scene, and nothing else.

    Not its shots: a scene and its shots are siblings produced by one
    generation (D3), not parent and child in the dependency graph.
    """
    return canonical_hash(
        {
            "kind": "scene",
            "order_index": scene.order_index,
            "heading": scene.heading,
            "summary": scene.summary,
            "location": scene.location,
            "time_of_day": scene.time_of_day,
        }
    )


def content_hash_for_shot(shot: Shot) -> str:
    """Every user-editable field of the shot.

    Leaving a field out here is not a small bug: from M4 the shot image's
    input_hash is built from this value, so an omitted field is one whose
    edit never invalidates the image generated from it.
    """
    return canonical_hash(
        {
            "kind": "shot",
            "order_index": shot.order_index,
            "image_prompt": shot.image_prompt,
            "motion_prompt": shot.motion_prompt,
            "duration_sec": _duration_at_column_scale(shot.duration_sec),
            "camera": shot.camera.value,
            "dialogue_kind": shot.dialogue_kind.value,
            "speech_text": shot.speech_text,
            "speaker_character_id": _optional_uuid(shot.speaker_character_id),
        }
    )


def script_input_hash(story_content_hash: str) -> str:
    """What would produce this script if it were generated right now.

    D2: read from the *current* provider configuration, not from whatever
    produced the existing rows. The same function supplies the job's
    idempotency key, so a row the UI shows as stale can never turn out to
    be a silent cache hit when the user presses Regenerate. The price is
    that changing LLM_MODEL, or bumping PROMPT_VERSION, marks every
    existing script stale — which is true, and operator-initiated.
    """
    return canonical_hash(
        {
            "kind": "script",
            "story_content_hash": story_content_hash,
            "provider": settings.llm_provider,
            "model": settings.llm_model,
            "params": SCRIPT_PARAMS,
        }
    )
```

```python
import uuid
from dataclasses import dataclass
from datetime import UTC, datetime

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession as DbSession

from framemeld.models.meld import Meld, Story
from framemeld.models.script import ArtifactState, Scene, Shot
from framemeld.script.hashes import script_input_hash

# Only these two states are recomputed. A row that is `empty` has nothing to
# be stale about; a `generating` row is owned by a worker that is about to
# write it; a `failed` row's problem is not its inputs. (D5)
_RECOMPUTABLE = (ArtifactState.FRESH, ArtifactState.STALE)


@dataclass(frozen=True)
class StalenessReport:
    stale_scenes: int
    stale_shots: int
    #: How many rows this call actually moved. Zero means the API can skip
    #: telling the user anything changed.
    changed: int


async def recompute_staleness(db: DbSession, meld_id: uuid.UUID) -> StalenessReport:
    """Bring every generated row in one Meld back in line with its inputs.

    The one place staleness is decided, so there is one answer rather than
    one per call site. Called after any edit to an upstream artifact —
    in M2 that means the story.

    Rows are never regenerated here and never deleted: regeneration costs
    money, so it stays an explicit user action (spec §4.1). All this does is
    flip `state` between `fresh` and `stale`, in both directions.

    Loads the rows rather than issuing a bulk UPDATE. A Meld holds at most
    30 shots (spec §1), and the D5 filter plus the per-row counts are far
    clearer in Python than in SQL. Revisit if a Meld ever holds thousands.
    """
    meld = (
        await db.execute(
            select(Meld).where(Meld.id == meld_id, Meld.deleted_at.is_(None))
        )
    ).scalar_one_or_none()
    if meld is None:
        return StalenessReport(0, 0, 0)

    story = (
        await db.execute(select(Story).where(Story.meld_id == meld_id))
    ).scalar_one_or_none()
    if story is None:
        return StalenessReport(0, 0, 0)

    expected = script_input_hash(story.content_hash)

    scenes = list((await db.execute(select(Scene).where(Scene.meld_id == meld_id))).scalars())
    shots = list(
        (
            await db.execute(
                select(Shot).join(Scene, Shot.scene_id == Scene.id).where(Scene.meld_id == meld_id)
            )
        ).scalars()
    )

    now = datetime.now(UTC)
    changed = 0
    for row in (*scenes, *shots):
        if row.state not in _RECOMPUTABLE:
            continue
        wanted = ArtifactState.FRESH if row.input_hash == expected else ArtifactState.STALE
        if row.state is not wanted:
            row.state = wanted
            row.updated_at = now
            changed += 1

    if changed:
        await db.flush()

    return StalenessReport(
        stale_scenes=sum(1 for scene in scenes if scene.state is ArtifactState.STALE),
        stale_shots=sum(1 for shot in shots if shot.state is ArtifactState.STALE),
        changed=changed,
    )
```

```python
async def save_story(
    db: DbSession,
    user_id: uuid.UUID,
    meld_id: uuid.UUID,
    text: str,
    if_content_hash: str | None = None,
) -> Story | None:
    meld = await get_meld(db, user_id, meld_id)
    if meld is None:
        return None

    # get_meld already eager-loaded this via selectinload, so no second
    # query is needed. A Meld with no Story returns None rather than
    # raising, so it becomes a 404 instead of a 500.
    story = meld.story
    if story is None:
        return None

    # Checked after the ownership funnel, never before: a precondition
    # failure on someone else's Meld would confirm that Meld exists.
    # Optional because the first save after a page load has nothing to
    # compare against yet.
    if if_content_hash is not None and if_content_hash != story.content_hash:
        raise StoryConflict

    now = datetime.now(UTC)
    story.text = text
    story.content_hash = content_hash_for_story(text)
    story.updated_at = now
    # Editing a Meld's story updates the Meld. The dashboard renders
    # "updated {meld.updated_at}" on every card, so without this a user
    # who writes for an hour still sees their Meld labelled with its
    # creation date.
    meld.updated_at = now
    await db.flush()

    # The story is the root of the dependency graph, so its edit is the one
    # event that can invalidate anything downstream. Run here rather than in
    # the router so no future caller can forget.
    await recompute_staleness(db, meld_id)
    return story
```

```python
from dataclasses import dataclass
from decimal import Decimal
from typing import Any, Protocol


class ProviderError(RuntimeError):
    """An adapter failure, carrying its own retry verdict.

    The adapter decides, because only the adapter knows what a given
    provider's error means — one service's 429 is a transient queue, the
    next one's is a hard daily cap. Spec section 5.4 splits the world the
    same way: transport and 5xx retry, content refusals are terminal.
    """

    def __init__(self, message: str, *, retryable: bool) -> None:
        super().__init__(message)
        self.retryable = retryable


class ProviderTransportError(ProviderError):
    """The call did not complete: a timeout, a connection reset, a 5xx."""

    def __init__(self, message: str) -> None:
        super().__init__(message, retryable=True)


class ProviderRefusedError(ProviderError):
    """The provider understood and declined. Retrying spends money to be
    refused again, so this is terminal."""

    def __init__(self, message: str) -> None:
        super().__init__(message, retryable=False)


class ProviderResponseError(ProviderError):
    """A well-formed response with an unusable body. Terminal for the same
    reason: the model will almost certainly produce the same shape again,
    and each attempt costs."""

    def __init__(self, message: str) -> None:
        super().__init__(message, retryable=False)


@dataclass(frozen=True)
class ProviderResult:
    """Spec section 3.3. `cost_usd` must be what the provider actually
    reported, never an estimate — from M3 it is what credit settlement
    subtracts."""

    text: str | None
    bytes_: bytes | None
    cost_usd: Decimal
    provider: str
    model: str
    #: The raw provider response, kept for debugging a bad generation
    #: months later. Never parsed by anything but the adapter itself.
    raw: dict[str, Any]


class LLMProvider(Protocol):
    name: str
    model: str

    async def complete(
        self, *, system: str, user: str, json_schema: dict[str, Any]
    ) -> ProviderResult: ...
```

```python
import json
import re
from decimal import Decimal
from typing import Any

from framemeld.config import settings
from framemeld.providers.base import ProviderRefusedError, ProviderResult

# Deterministic rotations, so a test can assert an exact script. Chosen to
# exercise every value at least once across a handful of shots rather than
# to look like good direction.
_CAMERAS = ("establishing", "medium", "close", "wide", "insert")
_DURATIONS = ("3.00", "4.00", "5.00", "2.50")

_SENTENCE = re.compile(r"(?<=[.!?])\s+")

MAX_SHOTS_PER_SCENE = 5


class StubLLMProvider:
    """A local, deterministic LLM that costs nothing and never leaves the
    process.

    It is the default provider (see settings.llm_provider) so that the app
    runs and the whole test suite passes with no API key. Its output is
    *derived from the story* rather than fixed, because a stub that ignored
    its input would let a broken prompt-building path pass every test in
    this milestone.

    It reports `settings.llm_model` as its model so that script_input_hash,
    which reads the same setting, describes what actually ran.
    """

    name = "stub"

    def __init__(self) -> None:
        self.model = settings.llm_model

    async def complete(
        self, *, system: str, user: str, json_schema: dict[str, Any]
    ) -> ProviderResult:
        if not user.strip():
            # A real model asked to dramatise nothing would refuse or
            # hallucinate. Refusing keeps the failure honest and gives the
            # error path something to exercise.
            raise ProviderRefusedError("There is no story to work from yet.")

        scenes = []
        shot_number = 0
        for index, paragraph in enumerate(self._paragraphs(user)):
            shots = []
            for sentence in self._sentences(paragraph)[:MAX_SHOTS_PER_SCENE]:
                shots.append(
                    {
                        "image_prompt": sentence,
                        "motion_prompt": f"Slow {'push in' if shot_number % 2 else 'drift left'}.",
                        "duration_sec": _DURATIONS[shot_number % len(_DURATIONS)],
                        "camera": _CAMERAS[shot_number % len(_CAMERAS)],
                        # Biased to narration: lip-sync is unsolved cheaply
                        # (spec section 8), so the stub models the same bias
                        # the real prompt asks for.
                        "dialogue_kind": "narration" if shot_number % 3 == 0 else "none",
                        "speech_text": sentence if shot_number % 3 == 0 else "",
                    }
                )
                shot_number += 1
            if shots:
                scenes.append(
                    {
                        "heading": f"SCENE {index + 1}",
                        "summary": shots[0]["image_prompt"],
                        "location": "Unspecified",
                        "time_of_day": "day",
                        "shots": shots,
                    }
                )

        payload = {"scenes": scenes}
        return ProviderResult(
            text=json.dumps(payload),
            bytes_=None,
            cost_usd=Decimal("0"),
            provider=self.name,
            model=self.model,
            raw={"stub": True},
        )

    @staticmethod
    def _paragraphs(text: str) -> list[str]:
        return [block.strip() for block in text.split("\n\n") if block.strip()]

    @staticmethod
    def _sentences(paragraph: str) -> list[str]:
```

```python
import uuid
from typing import Protocol

from arq import create_pool
from arq.connections import ArqRedis, RedisSettings

from framemeld.config import settings


class Queue(Protocol):
    async def enqueue(self, task: str, job_id: uuid.UUID) -> None: ...


class ArqQueue:
    """The real queue. Deliberately thin: it converts a job id to a string
    and hands it to arq, and knows nothing about what the task does."""

    def __init__(self, pool: ArqRedis) -> None:
        self._pool = pool

    async def enqueue(self, task: str, job_id: uuid.UUID) -> None:
        await self._pool.enqueue_job(task, str(job_id))


class RecordingQueue:
    """Records what would have been enqueued.

    A test double rather than a mock, so a test can assert *that* a job was
    dispatched without a Redis running and without arq's message format
    leaking into assertions.
    """

    def __init__(self) -> None:
        self.enqueued: list[tuple[str, uuid.UUID]] = []

    async def enqueue(self, task: str, job_id: uuid.UUID) -> None:
        self.enqueued.append((task, job_id))


_pool: ArqRedis | None = None


async def get_queue() -> Queue:
    """FastAPI dependency. The pool is process-wide and created on first
    use, for the same reason the Redis client is."""
    global _pool
    if _pool is None:
        _pool = await create_pool(RedisSettings.from_dsn(settings.redis_url))
    return ArqQueue(_pool)


async def close_queue() -> None:
    global _pool
    if _pool is not None:
        await _pool.aclose()
        _pool = None
```

```python
import uuid
from dataclasses import dataclass
from datetime import UTC, datetime

from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession as DbSession

from framemeld.hashing import canonical_hash
from framemeld.models.job import Job, JobKind, JobState

#: States in which an existing job is *the* answer: it is already going to
#: run, is running, or has already produced what was asked for.
_LIVE = (JobState.QUEUED, JobState.RUNNING, JobState.SUCCEEDED)


def idempotency_key(kind: JobKind, target_id: uuid.UUID | None, input_hash: str) -> str:
    """Spec section 5.4. Unique in the database, which is what makes a
    second Generate click free rather than expensive."""
    return canonical_hash(
        {
            "kind": kind.value,
            "target_id": None if target_id is None else str(target_id),
            "input_hash": input_hash,
        }
    )


@dataclass(frozen=True)
class JobDispatch:
    job: Job
    #: False means the caller must NOT push a message: the job is already
    #: queued, already running, or already finished.
    enqueued: bool


async def _by_key(db: DbSession, key: str) -> Job | None:
    return (
        await db.execute(select(Job).where(Job.idempotency_key == key))
    ).scalar_one_or_none()


async def ensure_job(
    db: DbSession,
    *,
    meld_id: uuid.UUID,
    kind: JobKind,
    target_table: str,
    target_id: uuid.UUID | None,
    input_hash: str,
) -> JobDispatch:
    """Find or create the one job for these inputs.

    Never creates a second row for the same (kind, target, input_hash): the
    unique index forbids it, and the point of the index is that the caller
    does not have to coordinate. A previously failed job is reset to
    `queued` in place rather than duplicated, because the unique key would
    otherwise make every failure permanent.
    """
    key = idempotency_key(kind, target_id, input_hash)

    existing = await _by_key(db, key)
    if existing is not None:
        if existing.state in _LIVE:
            return JobDispatch(existing, enqueued=False)
        # failed or cancelled: hand the same row back to the queue.
        # `attempts` is deliberately not reset — it is the row's history,
        # and the retry budget depends on it.
        existing.state = JobState.QUEUED
        existing.error = None
        existing.started_at = None
        existing.finished_at = None
        await db.flush()
        return JobDispatch(existing, enqueued=True)

    job = Job(
        meld_id=meld_id,
        kind=kind,
        target_table=target_table,
        target_id=target_id,
        input_hash=input_hash,
        idempotency_key=key,
        state=JobState.QUEUED,
        created_at=datetime.now(UTC),
    )
    try:
        # A savepoint, so losing the insert race does not poison the
        # caller's transaction. Two clicks 5 ms apart both see no existing
        # row; the unique index is what actually decides, and the loser
        # simply reads what the winner wrote.
        async with db.begin_nested():
            db.add(job)
            await db.flush()
    except IntegrityError:
        winner = await _by_key(db, key)
        if winner is None:  # pragma: no cover — the index says this cannot happen
            raise
        return JobDispatch(winner, enqueued=False)

    return JobDispatch(job, enqueued=True)


async def mark_running(db: DbSession, job_id: uuid.UUID) -> Job | None:
    """Claim a queued job, or return None if there is nothing to claim.

    arq can deliver the same message twice, and a retried job is re-queued
    under the same id. Returning None rather than running anyway is what
    stops one story being generated into two scripts.
    """
    job = (await db.execute(select(Job).where(Job.id == job_id))).scalar_one_or_none()
    if job is None or job.state is not JobState.QUEUED:
        return None
    job.state = JobState.RUNNING
    job.attempts += 1
    job.started_at = datetime.now(UTC)
    await db.flush()
    return job


async def mark_succeeded(db: DbSession, job: Job) -> None:
    job.state = JobState.SUCCEEDED
    job.error = None
    job.finished_at = datetime.now(UTC)
    await db.flush()


async def mark_failed(db: DbSession, job: Job, error: str) -> None:
    """Record a failure. The message is shown to the user, so it must say
    what went wrong without leaking a stack trace or an API key."""
    job.state = JobState.FAILED
    job.error = error[:2000]
    job.finished_at = datetime.now(UTC)
    await db.flush()
```

```python
_SYSTEM = """\
You are a shot-list editor for a short AI-generated film. You turn prose into \
a numbered list of scenes, each broken into shots.

Rules you must follow:
- Every shot lasts at most 5 seconds. This is a hard limit of the video model, \
not a stylistic preference.
- Every shot needs TWO prompts: `image_prompt` describes the frame as a still \
image, `motion_prompt` describes only what moves within it.
- `image_prompt` must be self-contained. It is sent to an image model that has \
not read the story, so name what is visible rather than referring back.
- Prefer narration, reaction shots and off-screen dialogue. Characters' mouths \
cannot be synchronised to speech, so on-screen dialogue looks wrong. Use \
`dialogue_kind: "on_screen"` only when nothing else will carry the moment.
- `speech_text` is what is heard over the shot, and empty when nothing is.
- Aim for 10 to 30 shots in total. Do not pad a short story.
"""

_USER = """\
Break this story into scenes and shots.

STORY:
{story}
"""


def build_messages(story_text: str) -> tuple[str, str]:
    return _SYSTEM, _USER.format(story=story_text)


class DraftShot(BaseModel):
    image_prompt: str = Field(min_length=1, max_length=4000)
    motion_prompt: str = Field(default="", max_length=2000)
    duration_sec: Decimal
    camera: CameraAngle = CameraAngle.MEDIUM
    dialogue_kind: DialogueKind = DialogueKind.NONE
    speech_text: str = Field(default="", max_length=4000)

    @field_validator("duration_sec", mode="before")
    @classmethod
    def _clamp_duration(cls, value: object) -> Decimal:
        """Clamped rather than rejected. Models ignore numeric bounds
        routinely, and losing a whole script over one bad number would be
        the wrong trade — while a value over 5 s would be rejected by the
        database CHECK anyway."""
        try:
            parsed = Decimal(str(value))
        except (InvalidOperation, TypeError):
            parsed = MIN_SHOT_SECONDS
        clamped = min(max(parsed, MIN_SHOT_SECONDS), MAX_SHOT_SECONDS)
        return clamped.quantize(Decimal("0.01"))

    @field_validator("camera", mode="before")
    @classmethod
    def _known_camera(cls, value: object) -> CameraAngle:
        """An invented angle costs this field's fidelity, not the script."""
        try:
            return CameraAngle(value)
        except ValueError:
            return CameraAngle.MEDIUM

    @field_validator("dialogue_kind", mode="before")
    @classmethod
    def _known_dialogue_kind(cls, value: object) -> DialogueKind:
        try:
            return DialogueKind(value)
        except ValueError:
            return DialogueKind.NONE


class DraftScene(BaseModel):
    heading: str = Field(default="", max_length=200)
    summary: str = Field(default="", max_length=4000)
    location: str = Field(default="", max_length=200)
    time_of_day: str = Field(default="", max_length=50)
    shots: list[DraftShot] = Field(default_factory=list)


class ScriptDraft(BaseModel):
    scenes: list[DraftScene]


def parse_script(text: str) -> ScriptDraft:
    """Turn a provider's response into a draft, or fail terminally.

    Every failure here is a ProviderResponseError, which is not retryable:
    a model that answered with prose once will answer with prose again, and
    each attempt costs. The user sees the message, so it says what happened
    rather than quoting the body back at them.
    """
    try:
        payload = json.loads(text)
    except (TypeError, json.JSONDecodeError) as exc:
        raise ProviderResponseError(
            "The model did not return a script. Try generating again."
        ) from exc

    try:
        draft = ScriptDraft.model_validate(payload)
    except ValidationError as exc:
        raise ProviderResponseError(
            "The model returned a script in an unexpected shape. Try generating again."
        ) from exc

    # Drop empty scenes before the count check, so "one scene with no shots"
    # is treated as the empty script it is.
    draft.scenes = [scene for scene in draft.scenes if scene.shots]
    if not draft.scenes:
        raise ProviderResponseError("The model returned an empty script. Try generating again.")

    _truncate_to_max_shots(draft)
    return draft


def _truncate_to_max_shots(draft: ScriptDraft) -> None:
    """Keep the first MAX_SHOTS shots in document order and discard the
    rest, dropping any scene left empty. Truncating from the end keeps a
    coherent opening rather than an arbitrary sample."""
    remaining = MAX_SHOTS
    kept: list[DraftScene] = []
    for scene in draft.scenes:
        if remaining <= 0:
            break
        scene.shots = scene.shots[:remaining]
        remaining -= len(scene.shots)
        kept.append(scene)
    draft.scenes = kept


async def apply_script(
    db: DbSession, meld: Meld, draft: ScriptDraft, input_hash: str
) -> tuple[int, int]:
    """Replace the Meld's script with this draft.

    Replace, not merge: a regenerated script is a new script, and trying to
    match new shots to old ones would guess at an intent the user has not
    expressed. Their edits are protected by *not regenerating* — which is
    why staleness never regenerates on its own.
    """
    # A bulk delete; Postgres cascades to shots. synchronize_session=False
    # because nothing in this session should still be holding the old rows,
    # and the ORM's default strategy would issue a SELECT to find out.
    await db.execute(
        delete(Scene)
        .where(Scene.meld_id == meld.id)
        .execution_options(synchronize_session=False)
    )
    await db.flush()

    now = datetime.now(UTC)
    shot_count = 0

    for scene_index, draft_scene in enumerate(draft.scenes):
        scene = Scene(
            id=uuid.uuid4(),
            meld_id=meld.id,
            order_index=scene_index,
            heading=draft_scene.heading,
            summary=draft_scene.summary,
            location=draft_scene.location,
            time_of_day=draft_scene.time_of_day,
            content_hash="",
            input_hash=input_hash,
            state=ArtifactState.FRESH,
            created_at=now,
            updated_at=now,
        )
        scene.content_hash = content_hash_for_scene(scene)
        db.add(scene)

        for shot_index, draft_shot in enumerate(draft_scene.shots):
            shot = Shot(
                scene_id=scene.id,
                order_index=shot_index,
                image_prompt=draft_shot.image_prompt,
                motion_prompt=draft_shot.motion_prompt,
                duration_sec=draft_shot.duration_sec,
                camera=draft_shot.camera,
                dialogue_kind=draft_shot.dialogue_kind,
                speech_text=draft_shot.speech_text,
                content_hash="",
                input_hash=input_hash,
                state=ArtifactState.FRESH,
                created_at=now,
                updated_at=now,
            )
            shot.content_hash = content_hash_for_shot(shot)
            db.add(shot)
            shot_count += 1

    # The Meld has reached stage 2. Purely presentational — nothing gates on
    # stage — but the dashboard shows it, and a Meld with a script that still
    # says "story" is a lie the user can see.
    meld.stage = MeldStage.SCRIPT
    meld.updated_at = now
    await db.flush()
    return len(draft.scenes), shot_count
```

```python
import logging
import uuid
from dataclasses import dataclass

from arq.connections import RedisSettings
from arq.worker import Retry
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession as DbSession

from framemeld.config import settings
from framemeld.db import SessionLocal
from framemeld.jobs.service import mark_failed, mark_running, mark_succeeded
from framemeld.models.job import Job, JobState
from framemeld.models.meld import Meld, Story
from framemeld.providers.base import ProviderError
from framemeld.providers.registry import get_llm_provider
from framemeld.script.generation import SCRIPT_JSON_SCHEMA, apply_script, build_messages, parse_script
from framemeld.staleness import recompute_staleness

logger = logging.getLogger(__name__)

#: Spec section 5.4: three attempts. Counted on the job row rather than in
#: arq, so a redelivery after a worker crash cannot restart the budget.
MAX_ATTEMPTS = 3


@dataclass(frozen=True)
class JobOutcome:
    state: JobState
    #: Whether asking for this job again could plausibly succeed. Decided by
    #: the adapter (see ProviderError), never inferred from the state — a
    #: FAILED job may be a timeout worth retrying or a refusal that never
    #: will be, and the two look identical from outside.
    retryable: bool


async def run_generate_script(db: DbSession, job_id: uuid.UUID) -> JobOutcome:
    """Generate one Meld's script.

    Everything the arq task does except talk to arq, so it can be driven by
    an ordinary session with no Redis in the test suite.
    """
    job = await mark_running(db, job_id)
    if job is None:
        # Already running, already finished, or unknown. A redelivered
        # message must not generate the same script a second time.
        existing = (await db.execute(select(Job).where(Job.id == job_id))).scalar_one_or_none()
        state = JobState.CANCELLED if existing is None else existing.state
        return JobOutcome(state, retryable=False)

    meld = (await db.execute(select(Meld).where(Meld.id == job.meld_id))).scalar_one_or_none()
    story = (
        await db.execute(select(Story).where(Story.meld_id == job.meld_id))
    ).scalar_one_or_none()
    if meld is None or story is None:
        await mark_failed(db, job, "This Meld no longer exists.")
        return JobOutcome(JobState.FAILED, retryable=False)

    provider = get_llm_provider()
    system, user = build_messages(story.text)

    try:
        result = await provider.complete(
            system=system, user=user, json_schema=SCRIPT_JSON_SCHEMA
        )
        draft = parse_script(result.text or "")
    except ProviderError as exc:
        # The message reaches the user through jobs.error, so adapters and
        # the parser both phrase their errors for a reader, not a log.
        await mark_failed(db, job, str(exc))
        logger.warning("generate_script failed for job %s: %s", job.id, exc)
        return JobOutcome(JobState.FAILED, retryable=exc.retryable)

    await apply_script(db, meld, draft, job.input_hash)

    # The user may have edited the story while this ran. The rows just
    # written carry the hash of the story this job was queued for, so if
    # that is no longer current they are genuinely out of date and must say
    # so rather than claim fresh.
    await recompute_staleness(db, job.meld_id)

    await mark_succeeded(db, job)
    return JobOutcome(JobState.SUCCEEDED, retryable=False)


async def generate_script(ctx: dict, job_id: str) -> str:
    """The arq task. Owns the session and the retry decision; the work
    itself is in run_generate_script."""
    async with SessionLocal() as db:
        outcome = await run_generate_script(db, uuid.UUID(job_id))
        # Committed before any Retry is raised, so the recorded failure and
        # the incremented attempt count survive the re-queue. Raising first
        # would roll them back and the budget would never be spent.
        await db.commit()
        attempts = (
            await db.execute(select(Job.attempts).where(Job.id == uuid.UUID(job_id)))
        ).scalar_one_or_none() or MAX_ATTEMPTS

    if outcome.retryable and attempts < MAX_ATTEMPTS:
        # Exponential backoff: 2s, then 4s. A content refusal or a bad
        # response never reaches here — those are terminal by spec 5.4,
        # and retrying them would spend money to be refused again.
        raise Retry(defer=2**attempts)

    return outcome.state.value


class WorkerSettings:
    """arq's entry point: `arq framemeld.worker.WorkerSettings`."""

    functions = [generate_script]
    redis_settings = RedisSettings.from_dsn(settings.redis_url)
    #: Retries are decided above, from the job row, so arq must not add its
    #: own on top — two independent budgets would multiply.
    max_tries = 1
    job_timeout = 300
```

Note the session is closed before `Retry` is raised. arq treats `Retry` as control flow,
not an error, but raising it from inside `async with SessionLocal()` would still unwind
through the context manager — and the commit must be the last database act either way.

```python
import uuid
from datetime import datetime
from decimal import Decimal

from pydantic import BaseModel, ConfigDict, Field

from framemeld.models.script import MAX_SHOT_SECONDS, CameraAngle, DialogueKind


class ShotOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: uuid.UUID
    order_index: int
    image_prompt: str
    motion_prompt: str
    #: Serialised as a JSON string, not a float. A binary float cannot hold
    #: 4.05 exactly, and the client sends this value straight back on the
    #: next edit — a round trip through float would silently change it and
    #: the shot would look edited when it was not.
    duration_sec: Decimal
    camera: CameraAngle
    dialogue_kind: DialogueKind
    speech_text: str
    state: str
    content_hash: str
    updated_at: datetime


class SceneOut(BaseModel):
    """A scene's own fields, and the response to a scene PATCH.

    Deliberately without `shots`: update_scene selects the Scene without
    eager-loading the relationship, so a schema that declared `shots` would
    lazy-load under asyncio and raise MissingGreenlet. A field edit has no
    business returning the shot list either.
    """

    model_config = ConfigDict(from_attributes=True)

    id: uuid.UUID
    order_index: int
    heading: str
    summary: str
    location: str
    time_of_day: str
    state: str
    content_hash: str
    updated_at: datetime


class SceneDetail(SceneOut):
    """A scene with its shots, for the script listing — which does eager-load
    them. Unlike a bare `pass` subclass this adds a field, so it earns its
    existence."""

    shots: list[ShotOut]


class ScriptOut(BaseModel):
    scenes: list[SceneDetail]
    stale_scenes: int
    stale_shots: int


class ScenePatch(BaseModel):
    """Every field optional: the editor autosaves one field at a time, and
    a full-object PUT would let a stale tab clobber a field it never
    touched."""

    heading: str | None = Field(default=None, max_length=200)
    summary: str | None = Field(default=None, max_length=4000)
    location: str | None = Field(default=None, max_length=200)
    time_of_day: str | None = Field(default=None, max_length=50)


class ShotPatch(BaseModel):
    image_prompt: str | None = Field(default=None, max_length=4000)
    motion_prompt: str | None = Field(default=None, max_length=2000)
    #: Bounded here so an over-long shot is a readable 422 rather than a
    #: 500 from the database CHECK. Both exist on purpose: this one is the
    #: message, the CHECK is the guarantee.
    duration_sec: Decimal | None = Field(default=None, gt=0, le=MAX_SHOT_SECONDS)
    camera: CameraAngle | None = None
    dialogue_kind: DialogueKind | None = None
    speech_text: str | None = Field(default=None, max_length=4000)
```

```python
import uuid
from datetime import UTC, datetime
from decimal import Decimal

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession as DbSession
from sqlalchemy.orm import selectinload

from framemeld.jobs.service import JobDispatch, ensure_job
from framemeld.melds.service import get_meld
from framemeld.models.job import Job, JobKind
from framemeld.models.meld import Meld
from framemeld.models.script import ArtifactState, Scene, Shot
from framemeld.script.hashes import content_hash_for_scene, content_hash_for_shot, script_input_hash


class EmptyStory(Exception):
    """Generation was asked for before there was anything to generate from.

    Refused in the API rather than in the job, so it costs a 422 instead of
    a free-tier request — those are capped at roughly 200 a day (spec §6.2).
    """


async def get_script(
    db: DbSession, user_id: uuid.UUID, meld_id: uuid.UUID
) -> tuple[Meld, list[Scene]] | None:
    """One Meld and every scene in it, with shots eager-loaded, or None if
    the Meld is not this user's.

    Returns the Meld as well as the scenes so the router resolves it once
    rather than calling get_meld a second time for the story hash. Goes
    through get_meld first: that is the only place a Meld is resolved by
    id, and it is what makes an unauthorised read a 404.
    """
    meld = await get_meld(db, user_id, meld_id)
    if meld is None:
        return None

    result = await db.execute(
        select(Scene)
        .options(selectinload(Scene.shots))
        .where(Scene.meld_id == meld_id)
        .order_by(Scene.order_index)
    )
    return meld, list(result.scalars().all())


def count_stale(scenes: list[Scene]) -> tuple[int, int]:
    stale_scenes = sum(1 for scene in scenes if scene.state is ArtifactState.STALE)
    stale_shots = sum(
        1 for scene in scenes for shot in scene.shots if shot.state is ArtifactState.STALE
    )
    return stale_scenes, stale_shots


async def request_generation(
    db: DbSession, user_id: uuid.UUID, meld_id: uuid.UUID
) -> JobDispatch | None:
    meld = await get_meld(db, user_id, meld_id)
    if meld is None or meld.story is None:
        return None
    if not meld.story.text.strip():
        raise EmptyStory

    return await ensure_job(
        db,
        meld_id=meld_id,
        kind=JobKind.GENERATE_SCRIPT,
        target_table="melds",
        target_id=meld_id,
        input_hash=script_input_hash(meld.story.content_hash),
    )


async def get_job(
    db: DbSession, user_id: uuid.UUID, meld_id: uuid.UUID, job_id: uuid.UUID
) -> Job | None:
    if await get_meld(db, user_id, meld_id) is None:
        return None
    # Filtered on meld_id as well as id: a job id alone would let any
    # logged-in user poll any other user's job by guessing one.
    return (
        await db.execute(select(Job).where(Job.id == job_id, Job.meld_id == meld_id))
    ).scalar_one_or_none()


async def update_scene(
    db: DbSession,
    user_id: uuid.UUID,
    meld_id: uuid.UUID,
    scene_id: uuid.UUID,
    fields: dict[str, object],
) -> Scene | None:
    meld = await get_meld(db, user_id, meld_id)
    if meld is None:
        return None
    scene = (
        await db.execute(select(Scene).where(Scene.id == scene_id, Scene.meld_id == meld_id))
    ).scalar_one_or_none()
    if scene is None:
        return None

    now = datetime.now(UTC)
    for name, value in fields.items():
        setattr(scene, name, value)
    scene.content_hash = content_hash_for_scene(scene)
    # D4: `state` is deliberately untouched. A row the user just edited
    # holds what the user wants, so it is not out of date. What moves is
    # content_hash, which is what downstream artifacts read.
    scene.updated_at = now
    meld.updated_at = now
    await db.flush()
    return scene


async def update_shot(
    db: DbSession,
    user_id: uuid.UUID,
    meld_id: uuid.UUID,
    shot_id: uuid.UUID,
    fields: dict[str, object],
) -> Shot | None:
    meld = await get_meld(db, user_id, meld_id)
    if meld is None:
        return None
    # Joined to Scene so the Meld actually owns this shot. Selecting by
    # shot id alone would let a caller edit any shot in the system as long
    # as they owned *some* Meld.
    shot = (
        await db.execute(
            select(Shot)
            .join(Scene, Shot.scene_id == Scene.id)
            .where(Shot.id == shot_id, Scene.meld_id == meld_id)
        )
    ).scalar_one_or_none()
    if shot is None:
        return None

    now = datetime.now(UTC)
    for name, value in fields.items():
        if name == "duration_sec" and value is not None:
            # Quantised to the column's scale so the stored value and the
            # hashed value agree; see _duration_at_column_scale.
            value = Decimal(value).quantize(Decimal("0.01"))
        setattr(shot, name, value)
    shot.content_hash = content_hash_for_shot(shot)
    shot.updated_at = now
    meld.updated_at = now
    await db.flush()
    return shot
```

```python
import uuid
from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.ext.asyncio import AsyncSession as DbSession

from framemeld.auth.deps import CurrentUser
from framemeld.db import get_session
from framemeld.jobs.queue import Queue, get_queue
from framemeld.jobs.schemas import JobOut
from framemeld.script import service
from framemeld.script.schemas import (
    ScenePatch,
    SceneDetail,
    SceneOut,
    ScriptOut,
    ShotOut,
    ShotPatch,
)

router = APIRouter(prefix="/melds/{meld_id}", tags=["script"])

Db = Annotated[DbSession, Depends(get_session)]
Jobs = Annotated[Queue, Depends(get_queue)]

GENERATE_SCRIPT_TASK = "generate_script"


def _not_found() -> HTTPException:
    """A fresh instance per raise — see melds/router.py for why."""
    return HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Not found")


@router.get("/script", response_model=ScriptOut)
async def get_script(meld_id: uuid.UUID, user: CurrentUser, db: Db) -> ScriptOut:
    found = await service.get_script(db, user.id, meld_id)
    if found is None:
        raise _not_found()

    _meld, scenes = found
    stale_scenes, stale_shots = service.count_stale(scenes)
    return ScriptOut(
        scenes=[SceneDetail.model_validate(scene) for scene in scenes],
        stale_scenes=stale_scenes,
        stale_shots=stale_shots,
    )


@router.post("/script/generate", status_code=status.HTTP_202_ACCEPTED, response_model=JobOut)
async def generate_script(meld_id: uuid.UUID, user: CurrentUser, db: Db, jobs: Jobs):
    try:
        dispatch = await service.request_generation(db, user.id, meld_id)
    except service.EmptyStory:
        raise HTTPException(
            status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
            detail="Write some story first — there is nothing to turn into a script yet.",
        ) from None
    if dispatch is None:
        raise _not_found()

    # Committed *before* the message is pushed. The worker resolves the job
    # by id in its own session, so enqueueing first would race it to a row
    # that does not exist yet.
    await db.commit()
    if dispatch.enqueued:
        await jobs.enqueue(GENERATE_SCRIPT_TASK, dispatch.job.id)
    return dispatch.job


@router.get("/jobs/{job_id}", response_model=JobOut)
async def get_job(meld_id: uuid.UUID, job_id: uuid.UUID, user: CurrentUser, db: Db):
    job = await service.get_job(db, user.id, meld_id, job_id)
    if job is None:
        raise _not_found()
    return job


@router.patch("/scenes/{scene_id}", response_model=SceneOut)
async def patch_scene(
    meld_id: uuid.UUID, scene_id: uuid.UUID, payload: ScenePatch, user: CurrentUser, db: Db
):
    scene = await service.update_scene(
        db, user.id, meld_id, scene_id, payload.model_dump(exclude_unset=True)
    )
    if scene is None:
        raise _not_found()
    await db.commit()
    return scene


@router.patch("/shots/{shot_id}", response_model=ShotOut)
async def patch_shot(
    meld_id: uuid.UUID, shot_id: uuid.UUID, payload: ShotPatch, user: CurrentUser, db: Db
):
    shot = await service.update_shot(
        db, user.id, meld_id, shot_id, payload.model_dump(exclude_unset=True)
    )
    if shot is None:
        raise _not_found()
    await db.commit()
    return shot
```

```python
from decimal import Decimal, InvalidOperation
from typing import Any

import httpx

from framemeld.config import settings
from framemeld.providers.base import (
    ProviderRefusedError,
    ProviderResponseError,
    ProviderResult,
    ProviderTransportError,
)

#: Generous, because a 30-shot script from a free-tier model is slow. The
#: connect timeout stays short: a host that will not answer the handshake
#: is not going to answer the completion either.
_TIMEOUT = httpx.Timeout(120.0, connect=10.0)

#: Statuses worth another attempt. Everything else 4xx is a request we
#: built wrong, or a key problem, and retrying changes neither.
_RETRYABLE_STATUSES = frozenset({408, 409, 425, 429})


class OpenRouterLLMProvider:
    name = "openrouter"

    def __init__(self, transport: httpx.BaseTransport | None = None) -> None:
        if not settings.openrouter_api_key:
            raise ValueError("OPENROUTER_API_KEY is not set but LLM_PROVIDER=openrouter")
        self.model = settings.llm_model
        # Injected only by tests, via httpx.MockTransport. It is the one
        # seam that lets this adapter's error mapping be tested exhaustively
        # without a network or a budget.
        self._transport = transport

    async def complete(
        self, *, system: str, user: str, json_schema: dict[str, Any]
    ) -> ProviderResult:
        payload = {
            "model": self.model,
            "messages": [
                {"role": "system", "content": system},
                {"role": "user", "content": user},
            ],
            "response_format": {"type": "json_schema", "json_schema": json_schema},
            "temperature": 0.7,
            # Asks OpenRouter to report what the call actually cost. Free
            # models report zero; paid ones must report truthfully, because
            # from M3 this number is what credit settlement subtracts.
            "usage": {"include": True},
        }
        headers = {
            "Authorization": f"Bearer {settings.openrouter_api_key}",
            # OpenRouter uses these for its model-usage dashboard. Neither
            # is secret.
            "HTTP-Referer": "https://framemeld.local",
            "X-Title": "FrameMeld",
        }

        try:
            async with httpx.AsyncClient(
                timeout=_TIMEOUT, transport=self._transport
            ) as client:
                response = await client.post(
                    f"{settings.openrouter_base_url}/chat/completions",
                    json=payload,
                    headers=headers,
                )
        except httpx.HTTPError as exc:
            # str(exc) on an httpx error never contains the request headers,
            # so the key cannot leak through here.
            raise ProviderTransportError(
                f"Could not reach the language model: {type(exc).__name__}."
            ) from exc

        if response.status_code in _RETRYABLE_STATUSES or response.status_code >= 500:
            raise ProviderTransportError(
                f"The language model service returned {response.status_code}. "
                "This is usually temporary."
            )
        if response.status_code >= 400:
            # Deliberately does NOT include the body. A 401's body can echo
            # the key back, and this message reaches the user through
            # jobs.error.
            raise ProviderResponseError(
                f"The language model rejected the request ({response.status_code})."
            )

        try:
            body = response.json()
        except ValueError as exc:
            raise ProviderResponseError("The language model returned an unreadable reply.") from exc

        choices = body.get("choices") or []
        if not choices:
            raise ProviderResponseError("The language model returned no reply.")

        choice = choices[0]
        if choice.get("finish_reason") == "content_filter":
            raise ProviderRefusedError(
                "The language model declined to work with this story. "
                "Try rewording the parts it might have flagged."
            )

        return ProviderResult(

        return Decimal("0")
```

```ts
/** No response is ever worth waiting on forever: without this a hung
 *  backend leaves the editor saying "Saving…" with the close warning armed
 *  and no way for the user to tell that nothing is happening. */
const DEFAULT_TIMEOUT_MS = 15_000;

type RequestInitWithTimeout = RequestInit & { timeoutMs?: number };

async function request<T>(path: string, init: RequestInitWithTimeout = {}): Promise<T> {
  const { timeoutMs = DEFAULT_TIMEOUT_MS, signal, ...rest } = init;
  const timeout = AbortSignal.timeout(timeoutMs);

  let response: Response;
  try {
    response = await fetch(`${BASE}${path}`, {
      ...rest,
      // Required so the HttpOnly session cookie travels cross-origin
      // (web on :3000, api on :8000). Omitting this is the single most
      // common cause of unexplained 401s here.
      credentials: "include",
      // AbortSignal.any so a caller's own cancellation still works. Passing
      // only the timeout would silently ignore it.
      signal: signal ? AbortSignal.any([signal, timeout]) : timeout,
      headers: { "Content-Type": "application/json", ...(init.headers ?? {}) },
    });
  } catch (err) {
    // A deliberate cancellation is the caller's business — rethrow it
    // untouched so it is not mistaken for a failure and reported to a user.
    if (signal?.aborted) throw err;
    // Status 0 is this module's convention for "no answer at all". Callers
    // branch on 401 and 404; everything else, including this, falls through
    // to their "check your connection" path, which is the right message.
    throw new ApiError(
      0,
      timeout.aborted
        ? "The server took too long to respond."
        : "Couldn't reach the server.",
    );
  }

  if (!response.ok) {
    let detail = response.statusText;
    try {
      const body = await response.json();
      if (typeof body.detail === "string") detail = body.detail;
    } catch {
      // Body was not JSON; keep the status text.
    }
    throw new ApiError(response.status, detail);
  }

  if (response.status === 204) return undefined as T;
  return (await response.json()) as T;
}
```

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { ApiError, getJob, type Job } from "@/lib/api";

const INTERVAL_MS = 1500;

/** Poll one job until it stops moving.
 *
 *  Polling rather than websockets: a script takes seconds, the page is open
 *  while it runs, and a socket would be a second transport to operate for
 *  one screen. Revisit at M6, where renders take minutes.
 */
export function useJobPolling({
  meldId,
  jobId,
  onSettled,
}: {
  meldId: string;
  jobId: string | null;
  onSettled: (job: Job) => void;
}): { job: Job | null } {
  const [job, setJob] = useState<Job | null>(null);

  // Kept in a ref so a caller that rebuilds the callback each render does
  // not restart the interval — which would poll far faster than intended.
  const onSettledRef = useRef(onSettled);
  useEffect(() => {
    onSettledRef.current = onSettled;
  }, [onSettled]);

  useEffect(() => {
    if (!jobId) {
      setJob(null);
      return;
    }

    let cancelled = false;
    let timer: ReturnType<typeof setTimeout>;

    const tick = async () => {
      try {
        const next = await getJob(meldId, jobId);
        if (cancelled) return;
        setJob(next);
        if (next.state === "queued" || next.state === "running") {
          timer = setTimeout(tick, INTERVAL_MS);
        } else {
          onSettledRef.current(next);
        }
      } catch (err) {
        if (cancelled) return;
        // A 404 means the job is gone; anything else may be transient. Keep
        // polling through the transient case rather than stranding the page
        // on a single blip, but stop on 404 or there is nothing to find.
        if (err instanceof ApiError && err.status === 404) return;
        timer = setTimeout(tick, INTERVAL_MS);
      }
    };

    void tick();
    return () => {
      cancelled = true;
      clearTimeout(timer);
    };
  }, [meldId, jobId]);

  return { job };
}
```

```python
async def test_revoking_twice_keeps_the_first_timestamp(db):
    """Otherwise a leaked-and-revoked token's audit trail is rewritten by
    anyone who replays it."""
    from sqlalchemy import select

    from framemeld.auth.sessions import issue_session, revoke_session
    from framemeld.models.user import Session, User

    user = User(email="revoke@example.com", password_hash="x")
    db.add(user)
    await db.flush()
    token = await issue_session(db, user.id)

    await revoke_session(db, token)
    first = (await db.execute(select(Session))).scalar_one().revoked_at
    await revoke_session(db, token)
    db.expire_all()
    assert (await db.execute(select(Session))).scalar_one().revoked_at == first
```
